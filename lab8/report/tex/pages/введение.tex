\section*{Введение}
\addcontentsline{toc}{section}{Введение}

Телефонный справочник~--- одно из наиболее распространённых приложений для организации контактной информации. Подобные системы применяются как в персональных устройствах, так и в корпоративных средах для хранения, поиска и управления данными о контактах.

Фреймворк Qt представляет собой кроссплатформенный инструментарий для разработки приложений на языке C++. Он предоставляет обширный набор готовых компонентов пользовательского интерфейса, механизм сигналов и слотов для межобъектного взаимодействия, а также средства для работы с файлами, сетью и базами данных.

В данной работе реализовано приложение телефонного справочника с графическим интерфейсом, обеспечивающее хранение контактов с валидацией вводимых данных, поиск и сортировку записей, а также сохранение информации в файлы различных форматов.
